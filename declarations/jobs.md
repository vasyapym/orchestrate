Read before filing a box job. the source: the declarations split, 2026-11-26 (DECISION-3, the hermitage-3d records round).

### 1.6 Declarations
- skill repos (vasyapym/orchestrate, vasyapym/bytecheck): the owner commits and pushes them himself, or asks for it explicitly; vasyapym/orchestrate: the agent commits and pushes always (owner, 2026-11-23).
- runner (Windows TD): `C:\Users\v.argunov\agent-runner\` — the worker script + the clone; Scheduled Task `AgentRunner` fires every ~5 min (interactive logon, one instance, 4 h cap); mailbox: private `vasyapym/agent-jobs` (`jobs/open` → `jobs/done`). Unrestricted shell jobs by the owner's design (2026-11-23): per-command timeout (default 180 min), audit-echo of every command, `jobs/PAUSED` stop, the `%JOB%` token. Heavy work (e2e/bakes/agent sessions) is delegated here from the owner's MacBook via the mailbox.
- agent-jobs filing (owner, 2026-11-24; /usr/bin/git for network): `jobs/open/<unique>.md` — `dir:`/`timeout:` (default 180)/`lane:` headers; one ASCII cmd line per step; `%JOB%`/`%LANE%` substitute. Commit+push main as `job: <name> (<what>)`; jobs immutable — delete + refile new. Pickup ~5 min/lane; parallel jobs need separate worktrees + distinct ports. Done = commit `runner[<lane>]: <name> done` (never folder existence) → results `jobs/done/<name>/log.md`, delete after ingest. Never edit `jobs/BOARD.md`. Stops: `jobs/PAUSED` / `jobs/STOP` (commit+push; remove STOP after the finalize). Quick stop, no investigation: taskkill /PID <runner.ps1 pid> /T /F — never the job's cmd.exe alone (the runner runs on to the next command); the next tick writes ABORTED. a3 currently paused (`PAUSED.a3`). The box may be off — ask the owner whether it is on before expecting pickup (owner, 2026-11-24). Waits: the watcher files WITH the job (one commit names both; a heavy job may end by pushing its verdict to a public branch, then a plain API watcher covers it). A background sub-agent runs the blocking poll loop (fetch + grep the JOB NAME for the done commit — never the lane, 60 s steps) and reports back; never manual polls. Mid-loop the watcher reads no messages — retarget = the api interrupt + a fresh spawn; name the job before spawning the watcher. Jobs stay AV-clean: NO PowerShell scripts in jobs at all — the endpoint's heuristic blocks polling/wait loops iex or file-based alike (the lane-quiet-wait.ps1 lesson, 2026-11-25); quiet-gating happens from the orchestrator's side: a watcher sees the BOARD quiet, then files.
- Box facts: agent-jobs/MACHINES.md is the only home; do not copy lines here.
